# sistema_de_menus_restaurante
Aplicación sencilla desarrollada en Javascript para la gestión de menús en restauración

Aplicación de Restaurante - Gestión de Platos y Menús

Descripción
------------
Esta aplicación web permite gestionar platos y menús de un restaurante de manera sencilla y dinámica.  
Fue desarrollada utilizando HTML, CSS y JavaScript, con un enfoque práctico para la manipulación del DOM y la validación de datos en el navegador.

La interfaz está diseñada con una paleta de colores cálidos, fondo crema y estructura compacta, lo que facilita la lectura y el uso sin necesidad de desplazarse demasiado por la página.

Funcionalidades principales
----------------------------
- Visualización dinámica de platos y menús.  
- Agregar nuevos platos indicando nombre, descripción y precio.  
- Validación de los datos ingresados (solo letras para texto y números válidos para el precio).  
- Eliminación de platos de la lista disponible.  
- Creación de menús personalizados y asignación de platos a cada menú.  
- Interfaz clara, compacta y fácil de usar.

Tecnologías utilizadas
-----------------------
- HTML5: estructura del contenido.  
- CSS3: diseño y estilos visuales.  
- JavaScript (ES6+): lógica de la aplicación y manipulación del DOM.

Estructura del proyecto
------------------------
proyecto-restaurante/  
│  
├── index.html                 (estructura principal de la aplicación)  
├── style.css                  (hoja de estilos)  
└── actividad_restaurante.js   (lógica y funciones en JavaScript)

Instrucciones de uso
---------------------
1. Clonar este repositorio:
   git clone https://github.com/tuusuario/proyecto-restaurante.git

2. Abrir el archivo index.html en un navegador web.

3. Utilizar la interfaz para:
   - Agregar platos nuevos.  
   - Eliminar platos existentes.  
   - Crear menús.  
   - Añadir platos a los menús creados.

El contenido se actualiza dinámicamente sin necesidad de recargar la página.

Diseño y estilo
----------------
El diseño está inspirado en ambientes cálidos y acogedores, con un esquema de color crema y tonos naranjas y marrones.  
El estilo busca mantener una apariencia profesional, simple y agradable para el usuario.

Posibles mejoras futuras
--------------------------
- Guardar la información en LocalStorage para conservar los datos entre sesiones.  
- Adaptar completamente la interfaz a pantallas móviles (diseño responsive).  
- Incorporar funciones para editar platos y menús existentes.  
- Conectar la aplicación con una base de datos o API externa.
